# A.N.I.H.A.N. UI prototype

A responsive, front-end-only demo built with HTML, CSS, and vanilla JavaScript.

## Run

Open `index.html` in a modern browser. No build step, package install, or backend is required.

## Demo areas

- Public landing page with sign-in / registration modal
- Buyer harvest listings, filters, calendar toggle, save button, and pre-order flow
- Farmer dashboard with assisted entry and a post-harvest form
- Municipal admin dashboard with approval queue and CSV / print-to-PDF actions

All account actions and sample records are demo interactions; nothing is sent to a server.
